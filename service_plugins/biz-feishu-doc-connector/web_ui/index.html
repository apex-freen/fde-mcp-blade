⚠️ 前提条件（任一未满足时方法会返回 code -1 并给出原因）

  • plugin.json 配置：config.app_id 已填；config.app_secret 已由管理员录入插件密钥箱（文件里保持 ${app_secret} 占位符）
  • 飞书后台（企业管理员）：自建应用已申请并发布云文档/云盘相关权限（docx:document、drive:drive 等）
  • 权限可见性：以应用身份调用时，应用只能操作「自己创建或被共享给它」的文档/文件夹；要读写他人的文档，需先把该文档共享给应用
  • 文档 document_id 以 doxcn 开头；文件夹 folder_token 以 fld 开头
