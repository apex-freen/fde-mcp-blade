⚠️ 前提条件（任一未满足时方法会返回 code -1 并给出原因）

  • plugin.json 配置：config.corp_id / config.app_secret 已填；应用消息需 config.agent_id>0；群机器人推送需 config.robot_webhook（或用 recipients 配 type=robot）
  • 企业微信后台（企业管理员）：已创建自建应用并配置"企业可信 IP"（应用消息用）；成员在应用可见范围；按手机号反查/查详情需通讯录权限
  • 推群消息：先在目标群添加"群机器人"并复制 webhook 到配置；webhook 不经可信 IP 校验，但拿到地址即可推送，注意开启加签/关键字
  • 企业微信内部成员的收件标识是 userid（不是 openid）；无通讯录授权时 user_info 返回的手机号可能脱敏（138****）

应用文本消息（wecom.app.send_text）

以自建应用身份发送给成员；署名自动追加到消息末尾。

应用 Markdown 消息（wecom.app.send_markdown）

markdown 只支持部分语法，不支持表格/图片/横向分割线。

群机器人推送（wecom.robot.send）

webhook 地址一律取自配置（config.robot_webhook / recipients type=robot），不回显。

按手机号反查 userid（wecom.contact.search_user）

逐个号码查询并汇总：查到的进 user_list，查不到的进 not_found（含原因）。

按 userid 查成员详情（wecom.contact.user_info）

返回姓名/部门（id 数组）/手机号/邮箱/职位；手机号无权限时可能脱敏。查到的 userid 可直接回发消息表单用。
