⚠️ 前提条件（任一未满足时方法会返回 code -1 并给出原因）

  • plugin.json 配置：config.app_id / config.app_secret 已由管理员填入；发送需 config.default_sender 或传 sender（有 allowed_senders 白名单时须命中）
  • 飞书后台（企业管理员）：自建应用已开启机器人；im:message:send_as_bot、contact:user.base:readonly（日历还需 calendar:calendar）等权限已申请并发布生效
  • 发群消息：机器人已被拉进目标群；发个人消息：对方在机器人可用范围内
  • 日历能力以机器人身份调用，只对"应用可写/订阅的日历"生效；个人日历通常需用户授权（会返回权限错误，属预期）

发消息（feishu.im.send_*）

发送方恒为"应用机器人"（无法伪装真人）；卡片自动追加"发起人"署名行。

通讯录（feishu.contact.*）

飞书不支持按姓名检索；个人收件人请先用"反查用户"拿 open_id 再回"发消息"。

日历（feishu.calendar.*）

接口只认"毫秒时间戳"，本面板自动把上面的本地时间换算成毫秒后提交。
