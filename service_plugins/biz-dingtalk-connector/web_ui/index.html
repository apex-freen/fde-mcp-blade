⚠️ 前提条件（任一未满足时方法会返回 code -1 并给出原因）

  • 发个人（工作通知）：plugin.json 的 config.app_key / config.app_secret / config.agent_id 已由管理员填入；发送需 config.default_sender 或传 sender（有 allowed_senders 白名单时须命中）
  • 发群（群机器人）：config.robot_webhook（+加签时 config.robot_sign）已填，或 config.recipients 中预配了 type=robot 的机器人；不需要 app_key/app_secret
  • 钉钉开放平台（企业管理员）：自建应用已开通消息/通讯录权限并发布生效；目标成员在应用可见范围内；群自定义机器人已在群中添加
  • 钉钉个人收件人标识是 userId（不是 open_id），可用下方"通讯录"按手机号反查；webhook URL 含 access_token，属敏感凭证，面板不会回显

工作通知（dingtalk.app.send_*，发个人）

工作通知只能发给个人 userId；发群请用右侧"群机器人"。

群机器人（dingtalk.robot.send，发群）

群消息唯一通道。加签 secret 由 config.robot_sign 或 recipients 该机器人的 robot_sign 提供；webhook（含 token）不会回显。

通讯录（dingtalk.contact.*）

钉钉不支持按姓名/邮箱检索；个人收件人请先用"手机号→userId"拿到 userId 再回"工作通知"发消息。
