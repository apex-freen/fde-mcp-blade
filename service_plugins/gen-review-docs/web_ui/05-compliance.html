对着贵方 checklist 逐条核对，右列指向本目录内的证据页。

#评审人常问平台能力证据对应标准状态
Q01数据存在哪里？会不会上传云端？纯本地优先：数据存本地 MariaDB 与本地日志目录，默认不出内网02 / 01等保2.0-8.1.4.1, GDPR-Art.32已具备
Q02数据出境吗？无默认出境通道；云端桥接默认关闭，开启需人工配置并留痕01 / 02个保法-§38, GDPR-Art.44已具备
Q03谁能看数据？权限怎么分？RBAC 三级，支持设备级/功能级授权；admin 跳过校验03ISO27001-A.9已具备
Q04有没有最小权限原则？令牌按权限收敛，无授权能力对 AI 不可见03ISO27001-A.9.2, 个保法-§6已具备
Q05AI 会不会越权操作设备/服务？五重安全校验 + 四级风险分级03 / 06等保2.0-8.1.4.2已具备
Q06高危操作怎么拦截？谁审批？auth 级走审批；disable 级前置拦截并留痕04 / 03ISO27001-A.9已具备
Q07操作有没有留痕？能追溯吗？4 类结构化日志（命令/授权/令牌/技能）04等保2.0-8.1.4.3, GDPR-Art.30已具备
Q08日志能保留多久？能导出吗？按项目约定保留；支持 Excel/CSV/JSON 导出04等保2.0部分
Q09日志里会不会有个人信息明文？审计与日志边界强制单向打码，永不落原文02 / 04个保法-§51已具备
Q10个人信息怎么脱敏/加密？分层：离站打码 / 落库可逆加密 / 审计强制打码02个保法-§51, GDPR-Art.32已具备
Q11用户同意怎么记录？怎么撤回？用户级单独同意开关；同意/撤回均写审计02 / 04个保法-§29, GDPR-Art.7已具备
Q12账号能对接我们的 AD/域吗？支持 OIDC（授权码+PKCE）与 LDAP/AD bind03ISO27001-A.9.2已具备
Q13会话怎么失效？离职/停用能立即断吗？会话入库可撤销；停用/删除联动吊销；重启防复活03ISO27001-A.9.4已具备
Q14有没有默认账号/弱口令风险？安装期强制初始化随机密码；建议首登改密03 / 06等保2.0-8.1.4.1部分
Q15出安全漏洞怎么响应？多久修？分级响应 SLA（待按合同填写）06ISO27001-A.12.6待补
Q16版本怎么升级？会不会影响业务？镜像升级 + 幂等 DDL；插件热更无需重启08 / 01ISO27001-A.12.6已具备
Q17备份怎么做？坏了多久能恢复？backup.sh 一键加密备份 + restore08等保2.0-8.1.4.4已具备
Q18断网/云端不可用还能用吗？纯本地优先：本地链路不依赖云端01 / 08等保2.0已具备
Q19有没有第三方依赖/供应链风险？依赖锁定（Cargo.lock + vendor）；插件进程隔离06ISO27001-A.12.5部分
Q20做过什么测试？有报告吗？功能/安全/合规测试报告07ISO27001-A.14部分
