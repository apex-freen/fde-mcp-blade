04 审计样例

留什么痕、怎么查、怎么导出（脱敏）。

1. 审计范围（4 类）

类别日志表记录内容
命令调用gis_cmd_log谁、何时、调用了什么、参数与结果（打码后）、成功/失败与失败分类
授权变更gis_grant_log设备/功能授权的授予、变更、回收
令牌操作gis_token_log令牌签发、使用、吊销
技能加载gis_skill_log技能被索引、命中的记录

扩展审计（安全增强）

类别日志表记录内容
PII 处理gis_pii_audit哪个边界、哪类 PII、执行了什么动作，永不存原文
提示词注入gis_injection_audit检测到的注入尝试与处置
风险拦截gis_risk_intercept_logdisable 级与可见性拦截事件
操作与登录sys_oper_log / sys_logininfor后台操作与登录记录（请求/响应体已打码）

2. 日志保留与导出

项说明
保留期限审计日志按项目约定（建议 180 天）
导出格式Excel / CSV / JSON（接口 /biz/gis_report/export）
脱敏导出内容为打码后数据，不含 PII 原文
可复算导出附"口径说明"，客户可自行核对

4. 拦截记录样例

时间操作人目标风险等级拦截类型原因
2026-09-10 10:20:11ops01设备 门禁 / 开门disabledisable该能力已禁用
2026-09-10 10:22:35user02设备 空调 / 修改参数auth待审批高危需审批
口径说明：disable 拦截不写入调用日志，避免污染"调用成功率"分母；独立记入 gis_risk_intercept_log。
