03 权限矩阵

谁能看什么、能做什么、怎么接 AD、离职怎么办。

1. RBAC 权限矩阵

三级模型：用户 → 角色 → 权限，支持设备级 / 功能级授权。

角色设备查看设备控制服务调用高危操作后台管理审计查看
超级管理员✅✅✅✅✅✅
运维管理员✅✅✅需审批部分✅
业务用户✅按授权按授权❌❌❌
只读访客✅❌❌❌❌❌

上表为默认角色模板，实际以现场配置为准（对应表：gis_role / gis_permission / gis_user_role / gis_role_permission）。

2. 风险分级（四级）

等级含义放行策略
normal普通操作权限校验通过即执行
risk有风险记录审计 + 可配置二次确认
auth高危走审批工作流，批准后执行
disable禁用前置拦截，不执行并留痕

3. 令牌收敛与可见性

  • 工具收敛单入口：所有设备与服务汇聚为少量 MCP 工具入口，避免暴露面过大；
  • 按令牌收敛：令牌无权限的能力对 AI 不可见（既调不到，也看不到）；
  • 审批放行：auth 级操作生成审批单，审批人确认后执行。

4. SSO / IAM 对接

方式协议说明
OIDC 联邦OIDC Core 1.0（授权码 + PKCE）对接 Entra ID / ADFS / Keycloak / Okta 等
LDAP / ADRFC 4511（ldaps / StartTLS）账号 bind 校验，不保存目录密码
本地密码Argon2 哈希可作降级选项，企业可禁用
  • 授权归属：SSO 只做认证；授权仍以本地 RBAC 为准，IdP 组仅作角色建议；
  • 账号映射：已绑定 → 同名自动关联 → JIT 建档（默认最小权限）。

5. 会话生命周期

动作行为
登录签发令牌并写入会话表（gis_login_session）
登出按 jti 撤销会话 + 内存黑名单（立即失效）
停用 / 删除用户联动吊销该用户全部会话（立即生效）
服务重启预热黑名单，已撤销令牌不复活
续期（可选）refresh 单次轮换 + 重放检测（默认关闭）

6. 账号安全

  • 安装期 ops.sh init 强制初始化随机密码（数据库/JWT），避免默认弱口令；
  • 默认管理员建议首次登录后立即改密；
  • 密码使用 Argon2 哈希存储，不可逆。
