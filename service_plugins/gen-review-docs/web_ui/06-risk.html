06 风险评估

主动列出已知风险、可能性、影响与缓解措施及责任方。

1. 风险清单

#风险可能性影响缓解措施责任方
R1AI 越权操作设备/服务中高五重安全校验 + 四级风险分级 + 令牌收敛产品方
R2高危操作未审批被误执行中高auth 级强制审批；disable 级前置拦截产品方
R3个人信息明文泄露中高分层：离站打码/落库加密/审计强制打码产品方
R4账号被冒用 / 弱口令中高随机初始化密码；支持 SSO/AD；Argon2 哈希双方
R5离职人员会话未失效中中停用/删除联动吊销会话；重启防复活产品方
R6数据外传 / 出境低高默认纯本地、不出内网；云端桥接默认关双方
R7备份丢失 / 不可恢复中高加密备份 + 轮转 + 恢复流程演练双方
R8供应链 / 依赖漏洞中中依赖锁定（Cargo.lock + vendor）；插件隔离产品方
R9云端/网络不可用导致业务中断中中纯本地优先，本地链路不依赖云端产品方
R10审计缺失导致无法追责低中4 类结构化审计 + 独立拦截/PII 审计产品方

2. 越权（R1 / R2）

  • 预防：令牌权限收敛（无权限能力不可见）+ 五重校验；
  • 拦截：disable 级执行前拦截，auth 级进入审批流；
  • 追溯：拦截与审批均有独立审计记录。

3. 弱口令（R4）

  • 首次安装由 ops.sh init 生成随机数据库密码与 JWT 密钥；
  • 默认管理员建议首次登录立即改密；
  • 企业环境建议禁用本地密码登录，统一走 AD/OIDC。

4. 漏洞响应

等级描述响应时限修复时限
严重可远程利用 / 数据泄露待填写待填写
高危权限绕过 / 敏感信息暴露待填写待填写
中低一般缺陷待填写待填写
响应/修复时限需按交付合同填写；升级机制见 08 降级预案。

5. 供应链

  • 后端依赖通过 Cargo.lock 锁定，并使用 vendor/ 离线构建，构建结果可复现；
  • 插件为独立 Python 子进程，进程隔离，依赖在自身 requirements.txt 声明；
  • 文档目录为纯静态页面，不含可执行脚本。
