02 数据流图

数据从哪进、在哪处理、存哪、是否出境。

1. 一页纸数据流图

 用户/终端              本地边缘设备（内网）                     外部（默认关闭）
 ┌────────┐  输入   ┌──────────────────────────────────────┐
 │ 语音/文字│ ─────▶ │ ① 接入层  MCP / 智能体                │
 │ 业务系统 │        │ ② 治理层  鉴权→权限→时效→防绕过→限频  │
 └────────┘         │ ③ 处理层  LLM(本地/内网) + 插件(隔离) │
                    │ ④ 存储层  本地 MariaDB + 本地 logs/    │──▶ 云端桥接(可选，默认关)
                    └──────────────────────────────────────┘
                           数据不出内网（默认）
  • 进：用户指令 / 业务系统调用 / 设备上报（MQTT）；
  • 处理：权限校验后由插件或设备执行，敏感信息按分层策略打码/加密；
  • 存：本地 MariaDB + 本地日志目录；
  • 出：默认不出内网；云端桥接需人工开启（可选项）。

2. 存储位置

数据存储位置说明
业务与配置数据本地 MariaDB（apex_db）用户/角色/权限/设备/令牌/审批/审计等
消息正文本地 MariaDB整列可逆加密（AES-256-GCM）
应用日志本地 logs/已打码，无 PII 原文
上传文件本地 data/uploads/按业务约定
插件与模板本地 data/service-plugins/插件目录
备份本地 backups/（加密）见 08 降级预案

说明：不涉及公有云数据库；数据库为本地自建 MariaDB。

3. 涉及个人信息的字段

表字段数据类型处理方式
gis_user手机号 / 邮箱个人信息权限控制 + 展示打码
gis_user_messagemessage_content含 PII 的正文可逆加密（本人/授权者解密回显）
gis_cmd_logrequest_params / response_body调用参数/结果单向打码（不可逆）
gis_approval_requestparams审批参数原文加密 + 打码快照
gis_mqtt_message_logpayload_*设备指令/响应单向打码
sys_oper_logoper_param / json_result操作日志单向打码
gis_pii_auditmasked_samplePII 审计仅存打码样例，永不存原文

4. PII 分层策略

同一份 PII 检测结果，按"数据流向"执行不同动作：

边界动作说明
① 离站外发（云端 LLM/插件等）打码仅结构校验通过才处理；高危可配拦截
② 消息正文落库可逆加密（假名化）AES-256-GCM，本人/授权者可回显
② 审计落库（cmd_log/审批/MQTT）强制打码单向不可逆，永久
③ 应用日志强制打码业务代码禁止打印原文
  • 内置类型：身份证、手机号、银行卡（支持扩展邮箱/姓名/车牌/自定义）；
  • 结构校验：身份证 GB11643 校验位、银行卡 Luhn、手机号号段，避免误伤订单号；
  • 单独同意：用户级开关（默认关闭），置位/清零均写审计。

5. 保留期限

  • 审计日志（命令/授权/令牌/技能）：按项目约定（建议 180 天）；
  • 操作日志 / 登录日志：按项目约定；
  • 备份：保留最近 7 份（自动轮转）。

6. 零出境声明

本平台默认不向境外传输个人信息：无默认跨境通道，云端桥接默认关闭；如启用云端桥接，应另行完成跨境合规评估与单独同意。数据存储与处理均在客户内网内完成。
