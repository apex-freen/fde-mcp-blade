本插件基于宿主「一次调用 = 一个短生命周期进程 + 同步等待一次响应」的模型，仅适合请求-响应式的协议：


协议支持说明
HTTP / HTTPS✅ 已实现REST 通用请求，最常用
SOAP 1.1/1.2✅ 已实现本质为 HTTP POST + XML，自动组包/解析
MQTT✅ 受限实现发布/订阅协议，仅支持「请求主题 → 应答主题」一次性短连接模式
CoAP❌ 暂不支持内网极少见、生态不普及，暂无实际场景，暂不实现
gRPC❌ 暂不支持内网应用相对少见，且通用调用需 proto 定义或服务端开启反射，暂不实现
WebSocket❌ 暂不支持双向长连接 + 服务端主动推送，与一次性进程模型冲突，不适合本插件

详细说明见插件 README_ZH.md「协议支持矩阵」。
