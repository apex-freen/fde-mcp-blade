# 发布检查单

发版前逐项确认，未通过不发版。

## 1. 功能与安全回归

- [ ] 管理台构建通过：`npm run check`、`npm run build`
- [ ] 登录、权限、部门隔离按角色实测
- [ ] 五重安全与风险分级回归（鉴权 / 权限 / 时效 / 防绕过 / 频控）
- [ ] 审计四类留痕可查（操作 / 授权 / 令牌 / 登录），行为重放可用
- [ ] 影子演练 → 审阅 → 批准重放链路可用

## 2. 依赖与许可

- [ ] 前端依赖变更已记录，`docs/dependencies.md` 同步
- [ ] 新增依赖的许可证与 Apache-2.0 兼容
- [ ] 镜像基础版本与 MariaDB 版本已记录

## 3. 部署与回滚

- [ ] `docker compose` 全新安装通过（2 核 2G 环境）
- [ ] 从上一版本升级通过
- [ ] 备份与回滚脚本演练通过
- [ ] 非作者独立完成一次部署与回滚

## 4. 文档与发布物

- [ ] `CHANGELOG.md` 已写清新增、修复、兼容性变化
- [ ] README 的版本号、镜像标签与截图同步
- [ ] 发布说明标明支持的架构与已知问题
- [ ] 安全相关修复已在发布说明中标注

## 5. 发布后

- [ ] 创建标签与 Release，附发布说明
- [ ] 双仓库（Gitee / GitHub）同步
- [ ] 记录本次发布人与复核人
